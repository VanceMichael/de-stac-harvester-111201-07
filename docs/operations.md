# 本地运行说明

先运行单元测试，再执行演示命令。演示从干净临时目录发起真实请求并处理响应，不需要外部站点。
常规导入失败时返回非零退出码，事务中的原文和记录会一起回滚，可保留源文件再次处理。
查询模式只读取当前数据库，不会补采或删除来源数据。需要长期保留证据时，请备份整个数据库。
本地响应服务支持状态码、响应头、文本或 base64 字节正文；未配置路径返回未找到。
每条路径的脚本独立推进，最后一个响应会重复；可借请求记录核对调用顺序。
数据文件的路径均相对项目根目录，修改工作目录前请确认输入和数据库参数。

## 联合检索运行说明

`federate` 的状态保存在独立数据库（默认 var/federation.sqlite3），可重复执行：
游标未走完的来源从断点续传，已完成的来源重新翻页以追补晚发布资产；`--phase 2`
模拟目录排除瞬时故障并发布迟到资产。`--report-only` 只读取已保存状态，不发起请求。
翻页中的坏条目进入 quarantine 表并被点名到具体切片，对应来源保持 incomplete，
不影响其他来源入库。观测去重键只含集合、平台、观测时刻、足迹与处理版本；签名资产
地址作为临时定位保存，过期后以最近一次检索到的为准。
